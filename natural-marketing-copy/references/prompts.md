# Natural Marketing Copy Prompts

## Rewrite Landing Copy

```text
이 랜딩 페이지 문구에서 AI 티와 번역투를 제거해줘.

조건:
- 고객의 실제 장면에서 시작할 것
- 내부 추상어보다 고객 행동을 쓸 것
- "혁신적인", "완벽한", "차세대" 같은 과장 표현을 쓰지 말 것
- 제품이 실제로 할 수 있는 것만 말할 것
- CTA는 8어절 이하로 줄일 것
- 제목은 한눈에 읽히게 짧게 만들 것

출력:
1. 수정안
2. 왜 바꿨는지
3. 아직 과장되거나 애매한 claim
```

## Brochure Story Arc

```text
이 브로슈어 문구를 기승전결이 있는 고객 이야기로 다시 정리해줘.

구조:
1. 고객이 겪는 장면
2. 현재 방식의 답답함
3. 제품이 도와주는 다음 행동
4. 남는 결과물 또는 기록
5. 상담/데모/검증으로 이어지는 CTA

주의:
- 기능 나열로 쓰지 말 것
- 내부 전략어를 고객-facing 카피로 쓰지 말 것
- 영어식 SaaS 표현을 한국어 업무 문장으로 바꿀 것
```

## Copy QA

```text
이 문구를 copy gate 기준으로 리뷰해줘.

차단 기준:
- 내부 추상어
- 번역투/AI풍 표현
- 근거 없는 과장
- 자동화/확정 결과를 암시하는 claim
- 긴 제목/긴 CTA/긴 문장
- 첫 viewport에서 고객 장면이 약한 문제
- "문제는 ... 점입니다" 반복
- "이미/벌써/곧/매번" 같은 시간 부사와 동사 충돌

각 이슈마다 위치, 원문, 문제, 수정안을 표로 정리해줘.
```

## Turn Feature Into Human GTM Copy

```text
이 제품 기능 설명을 고객-facing GTM 문구로 바꿔줘.

입력:
- 기능 설명:
- 대상 고객:
- 고객이 지금 겪는 문제:
- 제품이 실제로 해주는 것:
- 아직 못 하는 것:

출력:
1. 한 문장 가치 제안
2. Before/After
3. Hero title/body
4. 브로슈어 섹션 문구
5. CTA 후보
6. 이메일 초안
7. 과장/AI 티 체크 결과
```
